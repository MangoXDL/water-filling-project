# Water filling game

## Description

The background will be a blue sky then every few seconds white clouds will slide in from the side of the sceen and some cloud will change to a grey color and will rain.
And the objective is to catch the rain/water with the jar, the clouds will also be moving so it is harder to catch the water.
Depending on how much water we catch will determine how much water we can use for the garden, if some plants dont get the rquired water they need then they will die.
There will also be some clouds that produce acid rain. We can also make it so you can trip if you run to fast.
And maybe we can sell plant and buy different jars so if we want to collect more water we can buy a bigger jar or if we want to avoid the acid rain we can buy a a closed jar
that is acid proof. We can also make it imitate the time and wether to real life
